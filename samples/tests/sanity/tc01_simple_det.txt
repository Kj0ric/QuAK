#
# Properties:
#   - Parent is deterministic: YES
#   - Parent is complete: YES (only symbol 'a')

#   - Child 1 is complete: NO (s1 has no outgoing transitions)
#
# Expected Behavior:
#   - getChildrenSize() = 2
#   - isDeterministic() on parent = true
#   - After synchronization: 1 child
#

#   - Child returns value 2 (single transition s0->s1)
#   - Parent contributes 1 per step
#   - Expected: flattening should succeed, output has states
#

#   - Max child return value = 2
#   - threshold <= 2: should be NON-EMPTY (true)
#   - threshold > 2: should be EMPTY (false)
#
# For isUniversal(LimSup, Max_f, threshold):
#   - All words go through child with max=2
#   - threshold <= 2: should be UNIVERSAL (true)
#   - threshold > 2: should be NOT UNIVERSAL (false)
