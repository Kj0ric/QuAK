# Legacy Source Snapshots

Files in this directory are intentionally not built.

They are historical snapshots or comparison baselines kept for reference while
the active implementation continues to live in `src/NestedAutomaton.cpp`.
`NestedAutomaton_OLD_V2.cpp` and related old-v2 files are not active backends.

Do not add these files to CMake targets unless you are deliberately creating a
one-off comparison tool.
