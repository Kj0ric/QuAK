# LimAvg + SumMinus final-continuation diagnostic.
#
# This fixture intentionally uses a mixed-sign child to exercise the current
# signed synchronization implementation. Under raw signed accumulation:
#
# - forced stop on `a`: -5
# - continue through f0 on `b`, then flush on the next `a`: eventually -1
#
# The formal SumMinus = -sum(abs(w_i)) convention would not treat +4 as an
# improvement. This fixture is therefore a production-path diagnostic and is
# checked against the explicit stop/continue split oracle.

@PARENT
final: all
a : 1, p0 -> p1
b : 0, p1 -> p0

@CHILD 0

@CHILD 1
final: f0 f1
a : -5, s0 -> f0
b : 4, f0 -> f1
